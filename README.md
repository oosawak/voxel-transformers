# 変形ボクセルモデル集（Voxel Transformers）

Gemini が設計した「乗り物・建物・生き物 → ロボット」の変形ボクセルモデル10件のギャラリーです。

- 各モデルのプレビュー表示
- MagicaVoxel 形式データ（.vox）と生成スクリプト（.py）のダウンロード
- [Voxel Valkyrie](https://oosawak.github.io/voxel-valkyrie/) のハンガーで変形を確認（`?unit=<key>` で直接開く）

モデルの正本データは sprite-stack-proto の gemini-transformers フォルダで生成し、
Voxel Valkyrie 側へは `convert_to_vv.py` で変換した `models-extra.js` として登録しています。
